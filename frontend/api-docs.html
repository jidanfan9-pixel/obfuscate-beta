基址与协议

当前 API 基址：读取配置中…

部署地址取自独立后端发布结果。浏览器构建通过 GitHub Actions variable LUAUGUARD_API_URL 配置。

GitHub Pages 仅托管静态前端；API 需要独立运行的 Node.js 后端。若显示“尚未配置”，表示前端还没有连接已发布的 API 地址。

请求/响应：UTF-8 JSON。无需 Authorization、Cookie 或其他凭据。源码限制为 256 KiB。

健康检查

GET /api/health（也支持 HEAD），无需认证。

curl "$API_BASE_URL/api/health"

成功：{"ok":true,"service":"luau-guard-api","version":"1.0.0"}

混淆源码

POST /api/obfuscate，请求头 Content-Type: application/json。

curl -X POST "$API_BASE_URL/api/obfuscate" \
  -H 'Content-Type: application/json' \
  -d '{"source":"local count = 3\nprint(count)","level":"strong"}'

请求字段

字段类型要求与含义
sourcestring必需、非空；UTF-8 最大 256 KiB。
levelstring可选，默认 standard。可用 compact、standard、strong。

处理等级

值行为
compact去注释、压缩空白；尽量保留字符串内容与必要换行。
standard在压缩基础上尝试重命名可识别的局部变量。
strong也尝试重命名函数参数与循环变量；模板插值中的标识符保持原名。

成功响应

{
  "code": "local __l0=3\nprint(__l0)",
  "stats": {
    "inputBytes": 28,
    "outputBytes": 24,
    "savedPercent": 14,
    "identifiersRenamed": 1,
    "tokens": 8
  }
}

savedPercent 反映字节数变化，标识符重命名可能使结果变长，因此可以是负值。

错误、CORS 与限流

状态含义
400JSON 无效、缺少 source 或源码为空。
403浏览器 Origin 不在 CORS allowlist。
404 / 405路由不存在或请求方法不支持。
413请求体或源码超过大小上限。
422混淆等级无效或遇到未闭合字符串。
429单进程、单来源 IP 每分钟超过 30 次；响应含 Retry-After: 60。

错误体形如 {"error":"错误说明"}。跨域预检 OPTIONS 返回 204；默认允许站点为 https://jidanfan9-pixel.github.io，可通过服务端 ALLOWED_ORIGINS 扩展。
